# 点云地面滤波系统

基于 Qt + PCL 的激光雷达点云地面滤波桌面应用，支持坡度滤波与 CSF 布料模拟滤波两种算法。

## 功能特性

- **多格式点云 IO**：支持 `.pcd`、`.txt/.xyz`、`.las/.laz` 格式读取与分类结果导出。
- **坡度滤波**：基于格网坡度与高度阈值，检测并剔除非地面点。
- **CSF 布料模拟滤波**：模拟布料下落过程估计地面，并增加高度连通分量后处理，有效剔除楼顶、平台等高处水平面。
- **可视化参数面板**：通过 Qt 界面实时调整格网大小、坡度阈值、分类阈值等参数。
- **结果导出**：将滤波结果保存为 `.las`、`.pcd` 或 `.txt`。

## 开发环境

- Visual Studio 2022
- Qt 5.14.2
- PCL 1.11.1
- LASlib（用于 LAS/LAZ 读写）

## 构建方式

1. 使用 Visual Studio 打开 `Project1.sln`。
2. 确认项目属性中 PCL、Qt、LASlib 的包含目录与库目录路径正确。
3. 选择 `Debug` 或 `Release` 平台，生成解决方案。
4. 运行生成的 `Project1.exe`。

> 注意：实际参与编译的是 `Project1/mainwindow8bom.cpp`，而非同目录下的 `mainwindow.cpp` / `mainwindow8.cpp`。

## 使用说明

1. 点击 **浏览...** 选择点云文件。
2. 在 **滤波方法** 中选择：
   - `坡度滤波`：基于格网坡度判断地面点。
   - `CSF布料模拟`：基于布料模拟估计地面。
3. 设置对应算法的参数（见界面参数说明）。
4. 点击 **开始滤波**，等待处理完成。
5. 点击 **导出结果** 保存地面点云。

## 界面参数说明

### 通用参数

| 参数 | 含义 |
|------|------|
| 格网边长 X / Y | 二维格网分辨率（m） |
| 高度阈值 | 格网内高差或点相对最低点的高度阈值（m） |

### 坡度滤波参数

| 参数 | 含义 |
|------|------|
| 坡度阈值 | 中心格网与邻域格网坡度的最大允许值 |
| 坡度计算方式 | 平均 / 最小 / 中值 |
| 邻域范围 | 3×3 或 5×5 |
| 使用动态阈值 | 根据局部坡度方差自适应调整阈值 |

### CSF 参数

| 参数 | 含义 |
|------|------|
| 布料分辨率 | 模拟布料格网间距（m） |
| 最大迭代次数 | 布料模拟迭代上限 |
| 分类阈值 | 点与布料高差小于该值判为地面（m） |
| 布料硬度 | 1（软）/ 2（中）/ 3（硬） |
| 时间步长 | 模拟时间步长 |

## 算法说明

### 坡度滤波

将点云投影为二维格网，比较每个格网与邻域格网的最小高程差，计算局部坡度。坡度大于阈值或点明显高于格网最低点的点被判为非地面。

### CSF 布料模拟滤波

1. 翻转点云 Z 轴并剔除无效点；
2. 按布料分辨率建立碰撞格网；
3. 将布料置于点云上方，迭代模拟重力下落与内力约束；
4. 比较原始点云与布料高程，分类地面点；
5. **后处理**：对布料格网进行高度约束连通分量分析，保留最低连通区域作为地面，剔除楼顶、平台等高处物体。
